# Actividad formativa 2: Aplicación simple en Java

Proyecto académico sencillo que demuestra clases, atributos, objetos, constructor y métodos.

## Archivos
- `Estudiante.java`: define la clase Estudiante, sus atributos, constructor, getters y método para mostrar información.
- `Principal.java`: crea un objeto Estudiante y muestra sus datos.

## Cómo ejecutar
Guarda ambos archivos en la misma carpeta. Abre una terminal en esa carpeta y ejecuta:

```bash
javac Estudiante.java Principal.java
java Principal
```

Personaliza el proyecto según las indicaciones de tu docente.
